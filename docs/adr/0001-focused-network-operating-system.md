# Build a focused network operating system

NetPF is a BSD-based network operating system focused on routing, firewalling, and related network-appliance services, rather than a general-purpose BSD distribution or a firewall GUI around an otherwise general host. User-facing virtualization, VMs, jails/containers, NAS features, and arbitrary application hosting are out of scope so the OS can remain purpose-built and small. This captures the product scope stated in the project research; the particular BSD family remains undecided.
