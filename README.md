# NetPF

NetPF is a focused, declarative BSD network operating system powered by PF.

See the [architecture](docs/architecture.md) for the current design baseline and [research notes](docs/research.md) for its source material.

The first implementation PRD is [the Poudriere-built ZFS base system](docs/prd/0001-poudriere-zfs-base-system.md).

Build-host setup and image commands are documented in [Building the first NetPF image](docs/building.md).
